Clinical Lab Analysis System

A controlled, self-correcting generated-code pipeline for answering predefined clinical laboratory questions over the MIMIC-III (Medical Information Mart for Intensive Care) hospital dataset.

Team: Hala Hillou · Dana Nmarny · Anas Khoury · Alon Engel

  • MIMIC-III
  • Python · pandas
  • Streamlit

  • 2026

Research question

How can laboratory test results recorded during a hospital admission be used to automatically and reliably answer a limited, well-defined set of clinical laboratory analysis questions about hospitalized patients?

How it works

For every question, the system generates a short, readable Python snippet, executes it, validates the output against structural and clinical rules, applies a bounded rule-based correction if needed, and presents the result together with the code that produced it. The trusted default path answers 12 predefined question types from a single question registry; an optional, off-by-default "Advanced: AI writes code" mode extends the same pipeline to free-form questions inside a hardened sandbox.

Every run is fully auditable: the UI shows the final result alongside the generated code, the validation audit, and the complete correction history — the user can always see how an answer was produced, not just the answer itself.

Why it matters

Clinical relevance

Fast, correct answers about abnormal results, trends, and admission-level summaries support bedside review by a doctor and reproducible, exportable analysis by a researcher — without either user writing SQL or pandas code themselves.

Software-engineering relevance

A concrete case study in building an auditable "generated code" system — one that shows its work, checks its own output, attempts to repair itself, and only cautiously extends into open-ended code generation by a large language model (LLM) behind a sandbox.

Safety in a sensitive domain

Healthcare data raises the cost of a wrong or hallucinated answer. Restricting the system to a fixed, validated question registry by default — and allowing free-form LLM-authored code only inside a hardened sandbox — is itself a design decision about how much autonomy to give generated code.

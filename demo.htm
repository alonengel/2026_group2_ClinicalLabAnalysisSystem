The system in action

Demo & Screenshots

A complete visual walkthrough of the Streamlit application: the role-based entry point, every one of the 12 supported questions running on real data from MIMIC-III (Medical Information Mart for Intensive Care), and the transparency features — natural-language input, the validation audit, and the self-correction loop. Click any screenshot to view it full size.

Welcome screen and role-based workspaces

The app opens on a Welcome page with two role cards — Doctor (fast admission-level review) and Researcher (dataset-level, reproducible analysis) — each leading to a workspace that surfaces its role's questions first as clickable cards, with a switch-role button in the header. Both workspaces share the same backend pipeline and analysis panel.

The 12 supported questions

Each run shows a color-coded status, summary metric cards, a five-step Pipeline Explanation strip (question selected → code generated → execution → validation → correction), an optional trend chart, and four tabs: Final Result (with CSV download), Validation Audit, Correction Attempts, and Generated Code.

Transparency features

The system never shows just an answer — every result is accompanied by the code that produced it, the validation rules it passed, and any correction attempts along the way.

Want to run it yourself? The User Manual has the full installation and run instructions, and the source code is linked on the Downloads page.
